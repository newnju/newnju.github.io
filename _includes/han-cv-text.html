{%- comment -%} 履历条目里的日期 → 统一包一层 .han-cv-date（样式见 _han.scss 第 19 节） -------------------------------------------------------------------------- 数据里日期的位置本来不统一：任职 / 交换 / 学历条目写在最前面 （「2024.12 – 2025.05：上海交通大学…」），学历块的大标题写在最后面 （「…广播电视编导（130305），2017.09 – 2021.06」），项目写在一对括号里。 这里按 cv_mode 分两种拆法把日期摘出来包好，样式就统一了。 判定条件收得很紧：拆出来的那一截必须够短（≤ 32 字）且含四位年份，否则原样 输出 —— 万一某条文案在冒号前带了别的东西，也只是不包，不会把不该包的 内容染成时间色。条件分两步写（先长度再年份），一是好读，二是避开 Liquid 里 and / or 从右往左求值的坑。 用法：调用方先把三个 cv_ 变量 assign 好，再用 capture 把本文件的输出（是 HTML）存进一个变量打印出来；不要用 include 的具名参数传值 —— 不同 Liquid 实现对「参数传变量」支持并不一致，实测 liquidjs 会把变量名参数读成 true， 这段就静默输出空字符串：履历列表会被解析成空条目 + 缩进代码块，很难一眼 看出是哪里坏了。变量名统一带 cv_ 前缀，避免和调用方自己的变量撞名。 （本注释里刻意不写 Liquid 标签原文，免得被实现当成真标签解析。） cv_text 必填。一整条文案（日期在首或在尾）。 cv_sep 切分用的分隔符：日期在首时传条目用的冒号（中文「：」/ 英文「:」）， 日期在尾时传列表用的逗号（中文「，」/ 英文「, 」）。 cv_mode "head"（日期在首，默认）或 "tail"（日期在尾）。 {%- endcomment -%} {%- assign _t = cv_text | default: "" | strip -%} {%- if _t != "" -%} {%- assign _sep = cv_sep | default: "：" -%} {%- assign _mode = cv_mode | default: "head" -%} {%- assign _parts = _t | split: _sep -%} {%- assign _n = _parts | size -%} {%- assign _i = _n | minus: 1 -%} {%- assign _piece = "" -%} {%- if _mode == "tail" -%} {%- assign _piece = _parts | last | default: "" | strip -%} {%- else -%} {%- assign _piece = _parts | first | default: "" | strip -%} {%- endif -%} {%- assign _is_date = false -%} {%- if _n > 1 -%} {%- if _piece.size > 3 and _piece.size < 33 -%} {%- if _piece contains "19" -%} {%- assign _is_date = true -%} {%- elsif _piece contains "20" -%} {%- assign _is_date = true -%} {%- endif -%} {%- endif -%} {%- endif -%} {%- if _is_date -%} {%- if _mode == "tail" -%} {%- assign _head = _parts | slice: 0, _i | join: _sep -%} {{ _head }}{{ _piece }} {%- else -%} {%- assign _rest = _parts | slice: 1, 99 | join: _sep -%} {{ _piece }}{{ _sep }}{{ _rest }} {%- endif -%} {%- else -%} {{ _t }} {%- endif -%} {%- endif -%}
