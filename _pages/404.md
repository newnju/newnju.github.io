  404 页面（中英双语 + 太空侵略者小游戏 + 自助导航）
  --------------------------------------------------------------------------
  GitHub Pages 只认根目录的 /404.html，/en/ 下的不存在路径同样返回这一页，
  所以页面按中文渲染，再用脚本判断 location.pathname 是否以 /en 开头：是则
  换上英文正文、改 lang 与 title，把顶部导航、侧栏与页脚换成英文一套
  （数据见 n404-en-data）。

  页面上有两个动态部件，脚本挂掉时全部退化为静态文字，不影响可用性：
    1. 太空侵略者（2026-10 选定的 404 门面）：纯 Canvas 自绘的像素街机
       小游戏 —— 页面被外星人劫走了，打回去就能抢回来。开始遮罩挡着，
       一切动效都从用户点「开始」之后才发生，no-JS、打印与 reduced-motion
       下整个区块保持 hidden，只剩静态文字与自助导航。样式见
       _sass/_han.scss §31，文案见 n404-inv-i18n（中英两套），声音是
       WebAudio 合成的方波音效，默认开、可一键关（选择落 localStorage）。
    2. 自助导航：语言提示（浏览器主语言与 URL 语言不一致时互指对方）、
       坏地址自动修正（按归一化规则比对全站地址表，命中给正确地址并
       5 秒倒计时自动前往，可点「留在这里」取消）、模糊建议（编辑距离
       取最接近的三个，都不像就不硬塞）。

  此前门面上的博局镜（front matter 的 mirror: true）随这次改版卸下，
  门面让给街机屏幕；han-mirror 图式与 §30 的 .n404-mirror 样式保留，
  别处想用随时可以挂回去。

  数据由下方三个 JSON 提供：n404-en-data（英文换装的对表，取自
  navigation / ui-text / author，模板口径一致）、n404-pages（全站地址表，
  404 / feed 本来就不该被建议所以不进表）、n404-inv-i18n（游戏文案）。
{%- endcomment -%}
